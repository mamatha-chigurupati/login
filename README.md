# 🔐 Modern Login Page

A modern and responsive **Login Page** built using **HTML, CSS, and JavaScript**.
The project provides a clean user interface with form validation, password visibility toggle, and responsive design.

## 🚀 Features

* Modern glassmorphism UI
* Responsive design for desktop and mobile
* Email validation
* Password validation
* Show/Hide password functionality
* Remember Me checkbox
* Forgot Password option
* Google login button UI
* Login success message
* Smooth animations and hover effects

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the login page
* **CSS3** – Handles styling, layout, animations, and responsiveness
* **JavaScript** – Handles form validation and user interactions

## ⚙️ How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Make sure these files are present:

   * `index.html`
   * `style.css`
   * `script.js`
4. Open `index.html` in a web browser.

You can also use the **Live Server** extension in VS Code to run the project.

## 🔑 Login Validation

The JavaScript checks:

* Whether the email field is empty
* Whether the email contains a valid format
* Whether the password field is empty
* Whether the password contains at least 6 characters

If all validations are successful, a **Login Successful** message is displayed.

## 📱 Responsive Design

The login page automatically adjusts its layout according to the screen size, making it suitable for:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

## ⚠️ Note

This project is a **frontend login interface**.

It does not contain a real authentication system or database. The login validation is performed only on the client side using JavaScript.

For a real-world application, the frontend should be connected to a backend and database for secure authentication.
